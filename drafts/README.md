# Drafts

Finished pages that aren't assigned in class yet go here instead of in
`stories/`, `games/`, or `resources/`. They're not linked from anywhere on
the live site and won't be found unless someone has the exact URL — that's
enough privacy for a classroom site, but note it's not a real lock: anyone
with the direct link (or a search engine that stumbles on it) can still open
it.

**Workflow:**
1. Build the page here, e.g. `drafts/stories/salem.html`, using
   `templates/story-template.html` (or the matching template) as the
   starting point.
2. When you're ready to use it in class, just ask to have it moved/published
   — e.g. "publish drafts/stories/salem.html". That's a one-line move into
   `stories/salem.html` plus adding its card to `stories/index.html` (or
   `games.html` / `resources.html`), and it's live.
3. To pull something back down mid-unit, same thing in reverse.

Folders mirror the live site: `drafts/stories/`, `drafts/games/`,
`drafts/resources/`.
